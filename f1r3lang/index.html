What is f1r3lang? And, how do you spell it really?

The concurrent language for verifiable concurrent computing.

Most languages added concurrency later and have managed the damage ever since. f1r3lang starts there. Built on the rho‑calculus, every program is a set of processes passing messages on channels — parallel by default, deterministic in consensus, and secure by construction rather than by audit.

Formerly Rholang · proven on RChain · reborn on F1R3FLY

new helloworld, stdout(`rho:io:stdout`) in {
  contract helloworld( world ) = {
    for( @msg <- world ) {

    }
  } |

}

Why f1r3lang

A different starting point

Concurrent by default

The | operator runs processes in parallel — it's the core of the language, not a library. While sequential chains execute one transaction at a time, f1r3lang programs execute concurrently and still converge on identical state across every node.

Secure by construction

Channels created with new are unforgeable — no process can guess or reconstruct them. Capability security is grammar, not convention, and the reentrancy bugs that drained Solidity contracts have no syntax to exist in.

AI as a primitive

Contracts call language models the way other languages print a string: rho:ai:* channels reach GPT‑4, image and audio models, or local LLMs — with results cached deterministically so consensus replay still agrees.

Verifiable at scale

Programs execute on RSpace, a pattern-matching tuple space, metered by phlogiston and finalized by CBC Casper consensus. Parallelism with a mathematical guarantee that every validator reaches the same answer.

The headline act

Smart contracts that think

No other chain language ships AI as a built-in. In f1r3lang, a contract can query a model mid-execution, hand the result to the next process, and leave a verifiable record of the whole exchange on chain.

AI channels are non-deterministic by nature, so the runtime caches responses at execution and replays them during consensus — agents that act on chain without breaking the chain's agreement about what happened.

On-chain agents, off-chain models, one verifiable transcript.

ask-the-model.rhof1r3lang
new gpt4(`rho:ai:gpt4`) in {
  new ret in {
    gpt4!("Explain quantum computing
           in one sentence", *ret) |
    for (@response <- ret) {
      stdout!(response)
    }
  }
}

Lineage

A decade of theory, shipping

f1r3lang is the language formerly known as Rholang — the concurrent smart contract language that ran RChain's mainnet. The theory underneath it, the reflective higher-order π‑calculus, comes from decades of process calculus research into how independent systems communicate without shared state.

F1R3FLY rebuilt the machine around the language: a pure-Rust node, real numeric types, hierarchical data structures, a native test framework, and the AI channel system. Same calculus. New engine. New name.
